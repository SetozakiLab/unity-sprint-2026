# 01. オープニング

Unity Sprint 2026へようこそ。

この資料では、Unity Sprint 2026の目的、今日の流れ、担当範囲、進め方を確認します。

## Unity Sprint 2026とは

Unity Sprint 2026は、情報系の学生・Unity初学者向けに行うUnity / Git / GitHubの入門勉強会です。

この勉強会の目的は、Unityを完璧に理解することではありません。

まずは、以下の状態になることを目指します。

- 自分のPCでUnity制作を始められる
- Unityプロジェクトを開ける
- 簡単な操作やスクリプトを試せる
- 作ったものをGitHubに保存できる
- 今後の研究室活動や個人制作につなげられる

UnityやGitは、最初からすべてを理解しようとすると難しく感じます。

そのため、今回は「まず動かす」「まず作る」「まず保存する」ことを大切にします。

## 今日のゴール

今日のゴールは、次の3つです。

### 1. Unityを使える環境を作る

自分のPCに必要なツールを導入し、Unityプロジェクトを開ける状態にします。

導入する主なツールは以下です。

- Git
- GitHub CLI
- Visual Studio Code
- Unity Hub
- Unity Editor

### 2. Unityの基本を体験する

Unity Editorの基本操作を学び、C#スクリプトを使って簡単な動きを作ります。

ここでは、完璧なゲームを作ることよりも、Unityの基本的な考え方に慣れることを重視します。

### 3. 作ったものをGitHubに保存する

制作した内容をVSCodeのGit GUIからCommitし、GitHubに保存します。

Gitコマンドを暗記する必要はありません。

今回は、VSCodeの画面操作を使ってGitを扱います。

## 今日の基本方針

今日の基本方針は、次の3つです。

### 1. 完璧に理解しなくてよい

UnityもGitも、一度で全部理解する必要はありません。

まずは、手を動かして「こういう流れで作るんだ」と体験することを優先します。

### 2. 詰まったらすぐ呼ぶ

環境構築では、PCの状態によって予想外のトラブルが起きることがあります。

以下のような場合は、ひとりで悩まずにすぐ声をかけてください。

- インストールが進まない
- コマンドが実行できない
- エラーが出た
- 何を選べばいいかわからない

### 3. 小さく作って、こまめに保存する

最後のオリジナル制作では、最初から大きなものを作ろうとしなくて大丈夫です。

まずは小さく作り、動作確認し、GitHubに保存するところまで進めましょう。

## 今日の最終ゴール

- Unity Hubが使える
- Unity Editorがインストールされている

- VSCodeでGitの変更を確認できる

- 自分の制作物をGitHub上で確認できる
