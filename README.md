# Unity Sprint 2026

研究室新入生向けの Unity / Git / GitHub 入門勉強会資料です。

この勉強会では、Unityを完璧に理解することではなく、  
**自分のPCでUnity制作を始め、作ったものをGitHubに保存できる状態になること** を目標とします。

## 概要

### 日時

2026年5月8日（金）11:00〜16:00  
昼休憩：12:00〜13:00

### 対象

情報系の学生・Unity初学者

### ゴール

この勉強会が終わるころには、以下のことができるようになることを目指します。

- 自分のPCにUnity開発環境を構築できる
- Unity HubからUnityプロジェクトを開ける
- Unity Editorの基本操作を理解する
- C#スクリプトで簡単な動きを作れる
- VSCodeを使ってGit操作ができる
- GitHubに自分の制作物を保存できる
- 簡単なオリジナルコンテンツ制作を始められる

## 持ち物

- 個人PC
  - Mac / Windows どちらでも可
  - ストレージ容量は30GB以上の空きがあることを推奨
- 充電器
  - UnityはPCへの負荷が大きいため、電力を消費します
- マウス
  - 可能であれば持参してください
  - トラックパッドでも操作できますが、3Dシーンの操作はマウスの方がやりやすいです
